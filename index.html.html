Cara Simpan Sebagai PDF di HP & Laptop

Bagi Pengguna HP (Android / iPhone):

  1. Tekan tombol "Proses Cetak / Simpan PDF" di bawah.
  2. Pada tampilan pratinjau, klik menu dropdown Pencetak / Printer di paling atas.
  3. Pilih "Simpan sebagai PDF" (atau Save as PDF).
  4. Tekan tombol ikon PDF/Download untuk menyimpan langsung ke folder HP.

Bagi Pengguna Laptop / PC:

  1. Tekan tombol "Proses Cetak / Simpan PDF".
  2. Di jendela cetak, ganti Destination menjadi Save as PDF.
  3. Klik Save / Simpan dan pilih folder penyimpanan di laptopmu.
